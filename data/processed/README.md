## Processed Dataset

The processed datasets (`.npz`) used in this project are not included in this
repository due to GitHub file size limits.

Dataset details (v2 pipeline):
- Format: NumPy `.npz`
- Image resolution: 100 × 100 (resized from 128 × 128 with anti-aliasing)
- Classes: 0 = Smooth (elliptical/lenticular), 1 = Disk/Feature (spiral)
- `galaxy_dataset_splits_100x100.npz` — seeded stratified train/val/test
  (70/15/15); see `splits_manifest.json` for the exact split
- `galaxy_dataset_train_balanced.npz` — training split only, balanced with
  `RandomOverSampler` (validation and test are **never** resampled)

The datasets are generated by the scripts in `scripts/` and can be
reproduced by following the preprocessing pipeline (see README).
